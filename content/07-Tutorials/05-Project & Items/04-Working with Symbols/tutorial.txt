<title>Working with Symbols</title>

Symbols allow you to place multiple instances of an item in your project. This can save memory, since all instances of a symbol simply refer to the original item and it can speed up moving around complex objects, since internal properties such as segment lists and gradient positions don't need to be updated with every transformation.

<title>Creating Symbols</title>

To create a symbol from an item, just pass the item to the <api SymbolDefinition(item) /> constructor. When you create a symbol definition using an item, that item is automatically removed from the document.

To place instances of the symbol in your project, you can call <api SymbolDefinition#place>symbolDefinition.place(position)</api> on it, with the position where you want to place it.

For example, lets create a circle shaped path and place a few instances of it:

<paperscript height=100 split=true>
var path = new Path.Circle(new Point(20, 20), 30);
path.fillColor = 'red';

// Create a symbol definition from the path:
var definition = new SymbolDefinition(path);

// Place two instances of the symbol:
definition.place(new Point(80, 50));
definition.place(new Point(150, 50));
</paperscript>

<title>Placed Symbols</title>

A placed instance of a symbol is a <api SymbolItem /> and can be manipulated like any other <api Item />.

<paperscript height=100 split=true>
var path = new Path.Circle(new Point(20, 20), 30);
path.fillColor = 'red';

var definition = new SymbolDefinition(path);

var placed = definition.place(new Point(80, 50));

// Scale the place symbol by 50% in y direction:
placed.scale(1, 0.5);

// Rotate the symbol by 45 degrees:
placed.rotate(45);
</paperscript>

<title>Selecting Placed Symbols</title>
When you select a <api SymbolItem /> by setting <api Item#selected /> to <code true />, Paper.js draws its bounding box. This allows you to see how it has been transformed.

<paperscript height=100 split=true>
var path = new Path.Circle(new Point(20, 20), 30);
path.fillColor = 'red';

// Create a symbol definition from the path:
var definition = new SymbolDefinition(path);

// Place an instance of the symbol at the center of the view:
var placed = definition.place(view.center);

// Select the placed symbol:
placed.selected = true;

// Rotate the placed symbol by 45 degrees:
placed.rotate(45);
</paperscript>

<title>Symbol Definition</title>

When you create a symbol definition from an item, that item becomes its <api SymbolDefinition#item />. Editing the item is reflected in all its <api SymbolItem /> instances.

<paperscript height=100 split=true>
var path = new Path(new Point(20, 20), new Point(50, 50));
path.style = {
	strokeColor: 'red',
	strokeWidth: 10,
	strokeCap: 'round'
};

// Create a symbol definition from the path:
var definition = new SymbolDefinition(path);

// Place 30 instances of the symbol in the project in random
// positions in the view:
for (var i = 0; i < 30; i++) {
	var position = view.size * Point.random();
	var placed = definition.place(position);
}

function onFrame(event) {
	// Each frame, rotate the item of the
	// symbol definition by 1 degree:
	definition.item.rotate(1);
	
	// Add 0.2 degrees to the stroke color's hue:
	definition.item.strokeColor.hue += 0.2;
}
</paperscript>
