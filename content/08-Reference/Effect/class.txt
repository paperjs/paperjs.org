<div class="reference-class">


<p>A live effect, which derives what is drawn from an item without changing the item itself, as the effects in Illustrator do. Creating one registers it under its type, replacing any effect registered there before, and items use it by that type, see <a href="/reference/item#effects"><tt>item.effects</tt></a>, each through an <a href="/reference/effectinstance"><tt>EffectInstance</tt></a> with its own parameters.</p>


</div>

<div class="member-description hidden">

<div class="member-text">
	<p>The declared parameters of the effect by their names, as objects that describe them for hosts to build their settings from, with the default as their <code>value</code>, e.g. <code>{ label: &#39;Amount&#39;, type: &#39;number&#39;, range: [0, 100], value: 10 }</code>. 		<p>Read only.</p>

<div id="onapply" class="member">
<div class="member-link">
<a name="onapply" href="#onapply"><tt><b>onApply</b></tt></a>
</div>
<div class="member-description hidden">

<div class="member-text">
	<p>The function that applies the effect, called with the instance as <code>this</code>, and returning what the effect makes of the art that it gets, which it doesn&rsquo;t change.</p>
	
	
	
	<ul class="member-list">
		<h4>Type:</h4>
		<li>
			<tt>Function</tt>⟋<tt>null</tt>
		</li>
	</ul>
    <ul class="member-list">
<h4>Options:</h4>
<li><tt>event.art: <a href="/reference/item"><tt>Item</tt></a></tt> &mdash; the item to apply the effect to, or what  the effect before it returned</li>
<li><tt>event.item: <a href="/reference/item"><tt>Item</tt></a></tt> &mdash; the item that the instance is part of</li>
</ul>
	
	
</div>

</div>
</div>
